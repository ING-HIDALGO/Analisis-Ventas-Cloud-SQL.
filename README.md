Descripcion de proyecto (Project Description): Cloud-Based Sales Analysis
Este proyecto analiza un conjunto de datos de ventas tecnológicas procesado íntegramente en la nube. El objetivo principal fue identificar la cuota de mercado por marca y el rendimiento financiero de productos como Laptops y Mobile Phones.

 Flujo Técnico ( Technical Workflow)

Procesamiento en BigQuery: Se gestionó un volumen total de 275.689 unidades vendidas.


Optimización SQL: Se aplicó un filtro WHERE precio > 150.000 para centrarnos en productos de gama media y alta, asegurando que el análisis sea relevante para el negocio.


Visualización: Los datos se conectaron a Looker Studio, creando un gráfico circular que muestra la distribución de las marcas.

📈  Hallazgos Clave (Key Business Insights)

Cuota de Mercado: Existe una distribución muy competitiva donde marcas como Google lideran con un 5,2% , seguidas muy de cerca por Nokia (5,2%) y Apple (5,1%).


Impacto Financiero: El valor total analizado asciende a $5.132.070.354, lo que demuestra nuestra capacidad de manejar grandes cifras en la nube.

Segmentacion: Al segmentar por Laptop (138.019 unidades) y Mobile Phone (137.670 unidades), se obtuvieron promedios de precios precisos para cada sector.
